# TypeScript - EBAC

Repositorio de ejercicios desarrollados durante mi formación en TypeScript.

## Proyecto actual

Implementación de una función para calcular la edad de una persona a partir de su fecha de nacimiento.

El ejercicio incluye:

- Tipado estático con TypeScript
- Validación del formato de fecha
- Manejo de errores
- Manipulación de objetos Date
- Funciones tipadas
- Ejemplos de ejecución

## Tecnologías

- TypeScript
- Node.js
- npm

## Instalación

```bash
npm install
```

## Compilación

```bash
npx tsc
```

## Ejecución

```bash
node dist/app.js
```
